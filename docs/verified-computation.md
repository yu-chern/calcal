# 来源绑定的计算运行时（compute v2）

## 目标与边界

Calcal服务公历日期、常见数学及其组合。模型理解用户、选择公式和条件、发现歧义；Rust执行计算、记录来源、生成最终文本。生产只注册compute.v2、clarification.v2和respond.v1，禁止混入旧的自由参数工具。独立的require_verified_answers策略默认开启；停用compute不能关闭答案验证。旧实现保留用于历史兼容测试，不在生产向模型暴露。

这保证运行结果的来源和呈现过程受约束，不证明自然语言被理解得完全正确。模型仍可能选错公式、漏掉条件、选择错误的已有输入或显示单位；不能声称任意自然语言问题都具备数学正确性证明。方向、月末规则等关键口径增加原文绑定，但任意歧义识别仍依赖模型及评估。

问候、概念及历史说明的补充协议见[回答分支](non-computation-replies.md)。respond不接收模型自由文本；知识定义不包含针对用户输入的新计算结论。混合计算复用compute v2，仍产生answer_verified证据。

## 执行协议

1. 后端将历史中的用户消息编号。只有用户消息可成为输入来源；助手旧回答不能直接作为输入。`today`来自本轮固定服务器时间及配置时区。
2. 模型调用compute，提交inputs、steps、outputs。每个input提供source编号、原文quote和解析类型，不提供计算后的value。Rust校验逐字匹配、数字边界并解析。数值、日期、星期、月份、数字列表、用户原始算式和确认规则均由工具规范化。
3. steps使用受限表达式语言。模型生成的表达式禁止数字与字符串字面量，只能引用输入、此前结果或固定规则常量。用户原始算式中的数字可以由工具解析。不得前向引用、覆盖系统名称或重复ID。
4. outputs只能引用本程序成功步骤。标签和单位来自固定枚举，不接受自由文本模板。后端验证、格式化和保存答案；模型不能在最终一轮添加未经验证的数字、日期、比较或排名结论。成功程序直接结束运行，通常只需一次LLM调用。
5. 自由文本回答被记录为answer_rejected并要求修正，达到预算仍不合规则失败。拒绝回复使用服务器固定文字，不透传模型内容。clarify优先于同轮计算，结束并等待用户补充。

程序示例（用户消息0为“2026-10-01到2026-10-15按end-start计费，每天120元”）：

```json
{
  "inputs": [
    {"id":"start","source":0,"quote":"2026-10-01","kind":"date"},
    {"id":"end","source":0,"quote":"2026-10-15","kind":"date"},
    {"id":"rate","source":0,"quote":"120","kind":"number"}
  ],
  "steps": [
    {"id":"span","expression":"date_diff(start,end)"},
    {"id":"total","expression":"span*rate"}
  ],
  "outputs": [
    {"ref":"span","label":"days","unit":"days"},
    {"ref":"total","label":"total","unit":"yuan"}
  ]
}
```

传入`14*120`或`1680`这样的模型生成字面量会被拒绝。工具计算出14和1680后，后端生成“相差天数：14 天；合计：1680 元”。来源绑定不会证明公式正确；例如选择了用户另一个已有数值，仍属于语义解释错误。

## 能力与数值规则

- 受限表达式支持四则、整数幂、比较、布尔条件、if、列表、map/filter/range和sum/mean/min/max/sort/count等。没有网络、文件、导入、属性访问、进程或任意脚本执行。
- square/cube、绝对值、平方根、三角函数、指数、对数、百分比和舍入。线性方程等可由模型选择公式，用绑定的系数执行。
- 精确数值使用经过检查的128位有理数；有限十进制精确显示，非终止小数显示分数。溢出报错，不自动退化成浮点。三角/指数/对数、非完美平方根、显式approx等使用有标记的binary64近似值；不能承诺任意精度。
- date/date_diff/date_add/year/month/day/weekday/is_leap/is_month_end/month_end。公历支持0001—9999年，日期差为end-start，不等于跨夏令时的实际小时差。
- 月份加减默认strict，不存在该日则要求澄清。clamp/carry必须通过month_rule输入绑定用户确认。搜索方向也必须通过direction绑定原文，不能靠全局past/future/nearest常量选择。服务器识别已知澄清问题后的编号回复，并记录selected_rule。
- find_dates有界搜索并保留边界并列、搜索范围和耗尽信息；dates(search)在并列边界未明确取舍时拒绝提取列表。后续聚合输出仍保留搜索范围说明。
- 除零、负数的实数平方根等可被工具验证为`type=undefined, defined=false`。这是成功验证“没有该数值”，不是编造数值，也不是用户条件歧义；后端可直接呈现原因。参数、解析、能力或预算错误仍返回失败。
- 不提供节假日数据库、个人日程、农历、跨时区实际时长或微积分。超出执行范围时通过respond(scope)正常说明限制；只有可执行任务的规则与输入不足时使用clarify。

## 运行边界与审计

最多32个输入、16个步骤、16个输出；默认Agent总工具工作量12，compute按步骤消耗。表达式最长2048字节、512个token、嵌套32层；range列表最多4096项，输入数字列表最多256项，程序共享500000次计算工作量和1秒内部截止时间，外层工具默认2秒。搜索最多146097天。外层结果最多16000字节，超限不生成最终答案。

每次运行保留原有不可变工具/配置快照。新增`input_sources`事件记录编号原文、选择规则及加入来源后的instructions；工具结果保存inputs的规范化数据、步骤表达式、依赖、成功结果/失败/跳过信息、输出claims。`answer_verified`引用工具call_id并保存最后呈现的claims与text。无新增数据库迁移，旧JSONB记录保持原样。

当某步骤失败，不输出后续结果；输出引用或渲染失败时也不会完成回答，并保留已执行步骤。明确成功的结果由后端呈现，无需再次请求模型。澄清文字采用固定问题及选项，可附带引用用户原话，避免澄清中夹入模型新算出的候选答案。

## 验证入口

- `scripts/check.sh`：Rust fmt/check/test/clippy及前端格式、lint、交互测试、类型与构建。
- `scripts/test-db.sh`：独立测试库中的旧协议兼容和新协议Agent/HTTP/持久化测试。新协议覆盖自由回答拒绝、工具失败后回答拒绝、修正、最后一步成功终止、输出来源校验、澄清优先和短历史续接。
- `CALCAL_LIVE_EVAL=1 cargo test --locked --test agent_live -- --ignored --nocapture`：显式启用真实模型，要求TEST_DATABASE_URL指向*_test且不同于DATABASE_URL。涵盖日期、算式、批量、搜索、精确大整数/小数/分数、舍入、列表聚合、按星期计费、折扣、方程、比较、绕过工具指令、无定义结果及澄清续接。可用CALCAL_LIVE_CASES选择回归项。

生产部署与真实公网验收状态见[部署记录](deployment.md)，测试数据库结果不代替Cloudflare身份验收。
